# 第 14 章分镜：未来邮局

## 视觉方向

当代东方科幻绘本：瓷白空间、靛蓝线条、少量朱砂印章。未来邮局像一座安静的时间档案馆，不使用霓虹赛博或悬浮卡片。主角在同一条中轴线上观察包裹、知识图谱、信任桥、机器人工作台和最终信封。

## 动作设计

1. 两个未来包裹沿传送带到达，打开后不是文字列表，而是小型立体世界。
2. 四类人生复利采用四种机制：知识连线、技能阶梯、信任桥、健康选择树。
3. 独立思考用罗盘校准：证据、判断日志、反例测试逐步改变方向。
4. 内在价值四柱围绕人物升起，支撑同一个未来平台。
5. 机器人例子完整演出“突击失败 / 小步迭代 / 方法留下”的过程。
6. 结尾进入未来邮局操作台；信封封存后不切出，直接停留。
