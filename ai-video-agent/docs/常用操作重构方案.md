# 编辑器操作极简化方案

## 已确认的产品原则

这个编辑器是 AI 生成视频镜头的**轻量微调工具**，不是通用设计软件。用户只需要修正生成结果中的文字、位置、尺寸、样式或多余元素；不需要学习图层、复制、锁定、对齐等专业编辑操作，也不需要通过 AI 执行复杂修改。

因此，界面不保留“常用操作”八宫格，改为：

```text
选中元素 → 属性编辑 + 删除元素
编辑器全局 → 撤销 / 重做
```

## 只保留的按钮

| 位置 | 按钮 | 必要性与行为 |
| --- | --- | --- |
| 编辑器固定区 | 撤销 | 放弃上一条已保存的编辑；没有可撤销记录时禁用 |
| 编辑器固定区 | 重做 | 恢复刚撤销的编辑；没有可重做记录时禁用 |
| 选中元素的属性区底部 | 删除元素 | 移除当前镜头中不需要的元素；进入待保存预览，可在保存前取消，保存后仍可撤销 |

“删除元素”不与普通属性控件混在一起，使用危险样式并显示对象名，例如“删除：右下角装饰”。未选中元素时不展示或禁用。

## 不保留的功能

| 功能 | 结论 | 原因 |
| --- | --- | --- |
| 居中 | 删除 | 坐标和拖拽已能完成位置调整；一键居中会轻易破坏 AI 已生成的构图 |
| 复制 | 删除 | 复制属于手动搭建画面的工作，用户没有明确场景，也会带来重叠和 ID 管理问题 |
| 隐藏 | 删除 | 轻量编辑中“暂时不可见”和“删除”没有足够不同的用户价值；统一为删除 + 撤销 |
| 锁定 | 删除 | 适用于多人或复杂图层编辑；此处用户只做短暂的单人微调 |
| 置顶 / 置底 | 删除 | 层级概念不在轻量编辑范围内；现有实现实际是贴画面顶部/底部，名称也错误 |
| 归零 / 重置外观 | 删除 | 撤销已提供更精确的恢复路径；“重置哪些属性”容易产生歧义 |
| 对齐、分布、层级排序 | 不新增 | 属于专业排版功能，会扩大产品复杂度，与轻量微调定位冲突 |
| AI 复杂修改 | 不新增 | 复杂构图调整应通过重新生成镜头解决，不引入不可预测的复杂编辑链路 |

## 保留的非按钮编辑方式

这些不是新增操作按钮，而是属性编辑的必要能力：

- 直接编辑文字内容。
- 通过拖拽或 X/Y 输入调整位置。
- 调整尺寸、缩放、旋转、透明度。
- 对文本调整字号、颜色、字重和文字对齐。

用户要解决的典型问题可完整覆盖：

| 用户问题 | 解决方式 |
| --- | --- |
| 文字写错 | 修改文字内容 |
| 元素挡住主体 | 拖拽或修改坐标 |
| 元素太大、太小 | 调整尺寸或缩放 |
| 字不清楚、颜色不对 | 修改文本样式 |
| 多余装饰或错误元素 | 删除元素，必要时撤销 |
| 整体构图不合适 | 重新生成镜头，不在编辑器内做复杂修补 |

## 统一交互逻辑

1. 用户选中元素后，属性区显示该元素可编辑字段和“删除元素”。
2. 调整属性或点击删除时，画布立即显示预览，但不立即写入项目。
3. 待保存区明确列出改动，例如“删除：装饰圆点”或“主标题：字号 48 → 42”。
4. 用户可取消本轮修改，或保存修改。
5. 保存成功后，撤销 / 重做始终是唯一的恢复机制。
6. 对复杂构图问题，编辑器引导用户“重新生成镜头”，而不是叠加新工具或 AI 复杂操作。

## 实施清单

1. 移除“常用操作”分组及其八宫格布局。
2. 删除居中、复制、隐藏、锁定、置顶、置底、归零的入口和对应的 UI 调用。
3. 保留并强化“删除元素”：显示对象名、危险样式、待保存摘要与取消路径。
4. 将撤销 / 重做放到编辑器中始终可见的位置，不只放在历史页。
5. 保留现有属性编辑与拖拽能力；不开发对齐、层级、多选、隐藏列表或 AI 复杂修改。
