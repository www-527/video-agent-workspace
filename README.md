# Video Agent 工作区

本仓库保存整个 `video agent` 外层工作区中的应用代码、配套项目、脚本、创作方案和文档。

主要应用位于 `ai-video-agent/`，安装、配置与运行方式见该目录的 `README.md`。其他项目及视频方案保留原有目录结构。

## 上传范围

- 内层项目以实际文件收录，不是 Git 子模块；本地内层 `.git` 和历史仍保留。
- 保留代码、文档、脚本、配置示例以及未被项目忽略规则排除的图片等资源。
- 不上传密钥和真实 `.env`、运行数据库、依赖、模型、构建缓存、QA 产物、视频音频、压缩包及可执行程序；所有这些文件均保留在本地。
- 本仓库不是完整媒体备份。从仓库重新配置项目时，需要安装依赖并恢复所需的本地素材、外部工具和私有配置。
